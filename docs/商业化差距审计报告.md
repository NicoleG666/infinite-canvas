# 「无限画布」商业化差距审计报告

- 审计对象：`infinite-canvas-notes` v0.1.0（本地仓库当前代码）
- 审计日期：2026-11-12
- 审计方式：静态代码审计 + 配置/文档核对（未做运行时压测与渗透测试）
- 代码规模：`src/` 下 36 个 ts/tsx/css 文件，约 11,271 行；生产构建单 JS chunk 598,641 B、CSS 64,384 B
- 结论口径：以「大厂正式对外销售的商品化软件」为基准，而不是「个人可用的本地工具」

---

## 一、总体结论

**当前产品是一个完成度不错的本地优先画布原型，但距离可售卖的商业化软件仍有关键缺口，且缺口集中在数据可靠性、账号与付费、协作、工程交付四条主线上，而不是界面或画布交互。**

用一句话概括：**交互层已达「可演示、可自用」水平；产品层仍停留在「单浏览器、无账号、无同步、无备份、无付费、无运维」的原型状态。**

商业化成熟度评估（1–5 分，5 为可对外售卖）：

| 维度 | 评分 | 判断 |
| --- | --- | --- |
| 画布核心体验 | 4 / 5 | 节点、连线、分组、磁吸、整理、小地图、分享卡片完成度高 |
| 功能完整度 | 3 / 5 | 缺搜索、导入、版本历史、模板、导出图片/PDF 等闭环能力 |
| 数据与可靠性 | 1.5 / 5 | 单浏览器 IndexedDB，无备份、无同步、无冲突处理，存在静默丢数据路径 |
| 协作与权限 | 0.5 / 5 | 仅「分享快照」，无账号、无协作、无权限模型 |
| 工程质量 | 2 / 5 | 无 Git、无测试、无 CI、无 lint；大文件与全量渲染有性能天花板 |
| 安全与合规 | 1.5 / 5 | 本地明文存储，无隐私政策/ToS/CSP；分享内容可篡改 |
| 商业化基础设施 | 1 / 5 | `plan` 是本地可改字符串，无登录、支付、订阅、授权 |
| 可运营性 | 0.5 / 5 | 无埋点、无错误监控、无反馈入口、无灰度、无 i18n |
| 交付与发布 | 1 / 5 | 手动部署 dist；桌面端只是调用 `npm run dev` 的启动器 |

**不建议直接按「已可售卖」推进。建议先补齐 P0（数据安全底线 + 账号/云同步 + 付费权益服务端校验 + Git/CI），再谈功能扩张。**

## 三、差距清单（按维度）

> 工作量口径：**S** ≈ 1 人日内可完成；**M** ≈ 数人日到 1–2 人周；**L** ≈ 需要多人周或引入新体系/后端。
> 优先级：**P0** 阻断商业化上线；**P1** 首版可售必须；**P2** 规模化与差异化。

### A. 功能完整度与核心体验闭环

| # | 差距 | 现状证据 | 缺什么 / 影响 | 工作量 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| A1 | **无 JSON 导入** | `TopBar.tsx` L707–725 只有「导出 JSON / 复制数据」；`TODO.md` P2 明确「导入 JSON」未做 | 用户导出的备份无法还原，也无法迁移到新设备。数据出得去、回不来 | S | P0 |
| A2 | **无版本历史 / 快照** | 撤销栈是模块内存数组，上限 60，刷新即清空（`canvasStore.ts` L48、L58–63） | 误操作只能靠 60 步内撤销；没有「恢复到昨天版本」，不符合笔记类产品预期 | M | P1 |
| A3 | **无全局搜索** | 只有 `AssetPanel` 内的当前画布节点列表；`TODO.md` P3 记录「画布内搜索」未做 | 画布/节点一多就无法定位；跨画布检索完全缺失，弱于 Heptabase / Obsidian | M | P1 |
| A4 | **无模板与有效 onboarding** | 仅 `StartupHint.tsx` 一行空画布提示 | 新用户不知道「双击建节点 / 拖文件 / 拖加号连线」，转化率受损 | S | P1 |
| A5 | **无图片/PDF 导出、无演示模式** | `TODO.md` P3 记录 | 无法把画布交付给不看产品的人；商业化分享场景缺失 | M | P1 |
| A6 | **媒体资产无治理** | `idb.ts` 中 `files` 与 `apps` 独立 store；删除节点/文档不清 `files`（仅 `deleteAsset` 清，L287–301） | 附件越用越多、磁盘只增不减；无去重、无配额提示、无缩略图缓存 | M | P0 |
| A7 | **链接节点不抓取标题/摘要/OG 图** | `NodeCard.tsx` 链接节点仅存 `linkUrl` 与文本 | 与 Miro / Figma Jam 的链接卡片体验差距明显；纯本地实现受限，需要服务端代理 | M | P2 |
| A8 | **标签体系只有颜色** | `types.ts` L16 `tagColor`；`NodeCard.tsx` 五色标签 | 无文本标签、无标签聚合/筛选，知识管理深度不足 | M | P2 |
| A9 | **无移动端/触控适配** | `project-overview.md` 明确「不做移动端专门适配」 | 平板/触屏用户基本不可用；商业化场景少了 iPad 一类入口 | L | P2 |

**功能层判断：** 画布「单机编辑闭环」是完整的；缺的是「找得到、回得去、带得走」三类闭环（搜索、历史、导入导出/演示），这三类恰好是付费用户最常感知的能力。

### B. 数据与可靠性（最高风险区）

| # | 差距 | 现状证据 | 缺什么 / 影响 | 工作量 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| B1 | **数据只存在单浏览器** | `AGENTS.md` L7「全部数据保存在浏览器 IndexedDB，无后端、无账号」；`project-overview.md` L59–65 | 清缓存、换电脑、换浏览器 = 全部数据丢失；这是商业化产品的致命项 | L（或接第三方同步 M） | P0 |
| B2 | **多标签页整份覆盖写，静默丢数据** | 自动保存每 700ms `putDoc` 整份文档（`App.tsx` L269–298、`idb.ts` L175–183）；`idb.ts` L94 仅在 versionchange 时关闭连接 | 两个标签页同时编辑同一画布时，后写覆盖先写，无提示、无合并、无锁 | M | P0 |
| B3 | **无自动备份 / 回收站** | 删除画布仅 `confirm` 后 `deleteDoc`（`TopBar.tsx` L550、`App.tsx` L153–169） | 误删不可恢复；无导出快照、无本地回滚点 | M | P0 |
| B4 | **关闭页面可能丢最后 700ms 变更** | 自动保存是 700ms 防抖，未见 `beforeunload` / `visibilitychange` 强制落盘 | 用户改完立刻关标签页，最后一笔修改丢失 | S | P0 |
| B5 | **无存储配额与失败策略** | `idb.ts` 有 8s 超时与 `blocked` 处理，但无 `navigator.storage.estimate()`、无大文件拦截 | 媒体多时写入失败只在存储错误提示中出现，用户不知道「为什么存不进去」 | S | P1 |
| B6 | **无文档 schema 版本** | `CanvasDoc` 无 `schemaVersion` 字段（`types.ts` L90–95） | 后续字段演进只能靠容错读取，迁移不可控；商业化后改数据结构风险高 | S | P1 |
| B7 | **objectURL 未统一回收** | `TODO.md` P2 明确记录资产缩略图未 `revokeObjectURL` | 长时间使用内存持续增长，低端设备易崩 | S | P1 |
| B8 | **撤销快照成本高** | 每步保存整个 `nodes/connections/groups` 引用快照，60 步（`canvasStore.ts` L48–92） | 大画布内存占用高；且历史不持久化 | M | P2 |
| B9 | **分享链接不传媒体** | `share.ts` L31–37 明确剥离 `url/fileKey/fileName` | 收到分享只能看到媒体占位；大画布链接超 8000 字符（`TopBar.tsx` L700）易被聊天工具截断 | M（需服务端对象存储） | P1 |
| B10 | **无离线异常恢复机制** | 有存储失败降级（`App.tsx` L80–95），但无「草稿恢复 / 崩溃后重开」路径 | 崩溃或误关页面后，未落盘内容不可找回 | M | P1 |

**可靠性层判断：** 当前可靠性模型是「单机 + 尽力而为」。对免费工具可接受；对收费软件不可接受。**B1、B2、B3、B4 必须在对外售卖前解决，否则一次用户数据事故就足以摧毁口碑。**

## 六、Top 6 商业风险（按严重度）

1. **数据丢失风险（最高）**：单浏览器 + 无备份 + 多标签覆盖写 + 关闭页面丢尾巴。一次事故即可造成不可逆口碑损失。
2. **付费模型可被绕过**：`plan` 是本地字段，改 IndexedDB 即解锁。商业闭环不成立。
3. **无账号/无同步 → 无法形成留存与复购**：用户换设备即流失，付费意愿无法验证。
4. **交付不可控**：无 Git、无 CI、无测试、无监控，线上质量完全依赖个人手测。
5. **大画布性能天花板**：全量 DOM 渲染 + 每帧全量命中检测，重度用户会先撞墙。
6. **分享的安全与合规**：明文可篡改链接 + 无权限/过期/审核，既可能被用于钓鱼，也难以进入企业采购。
